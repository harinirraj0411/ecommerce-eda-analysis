# E-Commerce EDA Project

This project performs Exploratory Data Analysis (EDA) on the Online Retail dataset using Python.

## Features
- Data Cleaning
- Summary Statistics
- Missing Value Analysis
- Correlation Heatmap
- Distribution Plots

## Libraries Used
- Pandas
- Matplotlib
- Seaborn
